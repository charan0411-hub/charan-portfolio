Project 6: Charix

Charix is a small, dependency-free chat interface built around a notebook metaphor instead of a typical message-bubble UI. Messages are typed onto a serif "page" in real time; once the page fills, it animates off-screen and a fresh one takes its place. It's pure HTML/CSS/JS with no backend — plug in an OpenAI, Groq, or OpenRouter key (or any OpenAI-compatible endpoint) and it talks to the model directly from the browser.

AI used: Claude.

Licence : MIT.

Language Used: HTML, CSS, java script.
